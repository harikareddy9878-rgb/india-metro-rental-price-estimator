# Data card

## Sources

The project combines 7,691 rental listings from the Kaggle dataset `India House Rent Prediction` and 14,000 New Delhi rental listings from `New Delhi Rental Properties`. Both pages state an MIT licence. The source pages and download endpoints are recorded in `data/raw/source_manifest.json`.

## Preparation

Fields from the two inputs are mapped to one schema. Rows outside the accepted rent, area, and bedroom ranges are removed. Exact signatures across city, locality, property type, configuration, area, and rent are deduplicated.

The result contains 12,201 clean listings across five cities. The filtering counts are generated by code and saved beside the source manifest.

## Appropriate use

The table supports data cleaning, feature engineering, regression, baseline comparison, error analysis, and interval calibration.

## Known limitations

These are marketplace asking rents collected at different times. The combined data is not a probability sample of Indian households. Listings can be stale or promotional and may omit maintenance, deposit, exact location, floor, building quality, and negotiation. Results should not be treated as current market valuation.
