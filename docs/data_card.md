# Data card

## Origin

The dataset is generated locally with a fixed random seed. It is not scraped and contains no personal information.

## Scope

The sample contains 960 fictional listings across twelve Bengaluru localities. Monthly rent is derived from transparent assumptions for floor area, bedroom count, furnishing, property age, metro distance, parking, gated community status, and locality multiplier, followed by random variation.

## Appropriate use

The data supports feature engineering, regression, evaluation, and uncertainty communication. It must not be described as current Bengaluru market evidence.

## Known limitations

The generator simplifies building quality, exact location, amenities, negotiation, maintenance charges, lease terms, and market movement. Relationships in the generated data are easier to learn than relationships in a real listing marketplace.
